# Nditor の拡張機能と共同作業

共同作業中のスクリプトと拡張ブロックはホスト VM で実行されます。クラウドプロジェクトではサーバー VM がホストです。変数、モニター、レポーターブロックをクリックした結果はホストの値が参加者へ送信されます。

## 既存拡張の自動対応

拡張側の変更は不要です。参加者側で呼び出されたカスタム拡張のブロックは自動的にホストへ転送されます。クラウドでは既存の `util.target`、`Scratch.vm.runtime.targets`、変数・リスト、マウス・キー・タイマーの参照をホスト状態で更新します。保持したターゲット、変数、リストへの参照も維持します。runtime のイベントリスナーおよびタイマーにも対応します。

## 任意のホスト参照 API

カスタム拡張は `Scratch.nditor.readHost(request)` を使用できます。ブラウザの sandbox / unsandboxed 拡張とクラウド拡張の両方で Promise を返します。

```js
async value(args, util) {
    return Scratch.nditor.readHost({
        kind: 'variable',
        targetId: util.target.id,
        id: args.VARIABLE_ID
    });
}
```

| kind | 取得する値 |
| --- | --- |
| `variable` | 指定 ID の変数またはリスト。スプライトにない場合はステージを参照 |
| `target` | 指定スプライトの座標、向き、大きさ、コスチューム番号など |
| `timer` | ホストのプロジェクトタイマー |
| `answer` | ホストの「答え」 |
| `options` | 高度な設定。無限クローン数を保持するため ExtendedJSON 形式の文字列 |

`targetId` を省略すると、要求元が編集中のスプライトを参照します。取得できない変数やターゲットは `null` です。切断やタイムアウトは Promise を reject します。

## クラウドでの実行

カスタム拡張は WebAssembly 版 QuickJS の独立した JavaScript 実行環境で動作します。Nodeの `vm` やV8の実行環境を共有せず、`process`、`require`、Nodeのモジュール、ファイルシステム、WASI、ネイティブなネットワーク機能を公開しません。事前のSHA-256登録は不要で、拡張コード自体の変更も不要です。

1拡張のJSヒープは16MiB、1プロジェクトは最大4拡張（合計64MiBのJSヒープ）です。1回の評価は最大100ms、Promiseの継続は最大64件、全カスタム拡張の実行時間はプロジェクトあたり250ms/秒の予算を共有します。これらは拡張エンジンの制限であり、VM全体のOS上のメモリ使用量の上限を表すものではありません。OSコンテナによる隔離ではありません。

公開 HTTPS または data URL からコードを読み込みます。組み込み拡張は従来の VM 実装で動作します。カスタム拡張の JavaScript は独立した realm で実行し、Node API、ファイルシステム、サーバーの私設ネットワークへのアクセスを公開しません。

`Scratch.extensions.register()` はスクリプト読み込み中に呼び出してください。ブロックは同期の戻り値および Promise に対応します。`util.target` と `Scratch.vm.runtime` は呼び出し時のホスト状態を参照します。既存の変数・リストへの変更と `setXY`、`setDirection`、`setSize`、`setVisible`、`setCostume` はホストへ適用されます。`util.stackFrame` と `util.yield()` にも対応します。

DOM、WebGL、カメラ、ブラウザイベントに依存する処理はクラウドのこのローダーでは提供していません。`fetch` と `Scratch.fetch` は公開 HTTPS / data URL への GET、レスポンスの `text()` / `json()` に対応します。描画用 renderer を直接使う拡張はブラウザをホストとして使用してください。

通信はプロジェクト全体で同時4件、毎秒1件の補充・最大16件のバーストに制限します。1レスポンスは最大2MiB、1回の実行でホストへ適用する操作は最大128件です。ループバック・プライベートネットワークへの接続は、DNS解決時とリダイレクト先でも拒否します。

Pen の線・点・スタンプはホストから同期され、途中参加時にも既存の描画を再生します。高度な設定は変更操作とホストの確定状態の両方で同期されます。
